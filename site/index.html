What this checks

Only the canonical 18-decimal native event stream counts. Mint/burn and same-transaction outgoing funds cannot masquerade as retained payment. Amounts use exact integers, not floating point. The receipt is cross-checked against its referenced block.

Deployed report anchor

Our non-custodial contract stores publisher-scoped report hashes. It does not validate payment truth, and this page does not write to it. No report has been anchored as part of this demo.
